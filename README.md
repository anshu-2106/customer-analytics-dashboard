# Customer Analytics Dashboard

## Project Overview
This project analyzes customer purchasing behavior, revenue trends, payment methods, and state-wise performance using Python, Pandas, and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI

## Key Insights
- Total Revenue: ₹16.01M
- Total Orders: 99K+
- Total Customers: 96K+
- Average Order Value: ₹160.99
- Credit Card payments generated the highest revenue.
- São Paulo (SP) contributed the highest revenue.

## Dashboard Features
- Revenue KPI Cards
- State-wise Revenue Analysis
- Payment Type Analysis
- Monthly Revenue Trend
- Interactive Filters
